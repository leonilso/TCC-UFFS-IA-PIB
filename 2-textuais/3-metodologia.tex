\section{Delineamento de pesquisa}
Com base em seus objetivos, esta pesquisa possui caráter comparativo, pois avalia o desempenho preditivo de diferentes modelos aplicados aos mesmos alvos. Quanto à abordagem, é predominantemente quantitativa e emprega os métodos comparativo e estatístico. Quanto às fontes, caracteriza-se como documental, por utilizar séries obtidas em repositórios digitais de dados.

Sobre os procedimentos de coleta de dados, a pesquisa se enquadra como documental, pois utiliza dados de diferentes fontes, inclusive registros disponíveis em repositórios digitais. Segundo \citeonline{Gil}, a pesquisa documental pode recorrer a fontes diversas, para além de materiais impressos disponíveis em bibliotecas.

Quanto à abordagem, a pesquisa é predominantemente quantitativa, pois compara o desempenho dos modelos com base em medidas numéricas. Para \citeonline{LAKATOSMARCONI}, o método estatístico reduz os fenômenos a termos quantitativos e permite examinar sua natureza, ocorrência ou significado. As autoras também descrevem o método comparativo como adequado à comparação entre grupos \citem[p. 107-108]{LAKATOSMARCONI}.

\section{Procedimento de coleta de dados}

As variáveis foram selecionadas com base na dissertação de \citeonline{rebelo2022interpretabilidade}. Algumas variáveis utilizadas nesse estudo não estavam disponíveis para o Brasil ou não cobriam todo o período analisado, como as despesas ambientais do governo, o índice de eficiência jurídica e o índice de saúde fiscal. Indicadores como o IFGF (Índice Firjan de Gestão Fiscal) e o IPC-Jus (Índice de Produtividade Comparada da Justiça) possuem séries históricas mais curtas; dados sobre despesas ambientais também estão disponíveis para períodos mais recentes. A inclusão dessas variáveis poderá ser considerada em pesquisas futuras, caso haja séries compatíveis com a janela de análise. As variáveis selecionadas, suas fontes e os endereços eletrônicos dos dados estão relacionados na tabela \ref{tab:fontes_dados}. Os dados foram extraídos de três APIs (\textit{Application Programming Interface}, ou interface de programação de aplicações) e de uma fonte on-line sem API pública, cujos dados foram obtidos em formato de planilha. A série de desocupação combina duas pesquisas do IBGE: a PNAD Contínua (Pesquisa Nacional por Amostra de Domicílios Contínua), de 2012 a 2025, e a PME (Pesquisa Mensal de Emprego), de 2007 a 2011. Como essas pesquisas diferem quanto à faixa etária, à população pesquisada e à cobertura geográfica, a série combinada deve ser interpretada considerando essa quebra metodológica.

A primeira fonte foi a API de dados agregados do IBGE, onde nela existem informações econômicas, sociais e demográficas do Brasil. 


\begin{citacao}
	O IBGE possui uma Application Program Interface (API) de serviços de dados abertos que disponibiliza dados processáveis por máquina para qualquer cidadão ou sistema, permitindo a interoperabilidade e o enriquecimento a partir dos dados abertos disponibilizados. \citem[p. 2]{silva2024dados}.
\end{citacao}

A segunda API utilizada foi a API do BACEN (Banco Central do Brasil), onde foram extraídos dados das contas públicas do Brasil. Segundo o próprio \citeonline{bcb_dados_abertos} o "catálogo de dados, permite que os usuários encontrem os conjuntos de informações de seu interesse, entendam sua estrutura e suas limitações, e tenham acesso ao caminho para os dados."

A terceira fonte de dados via API foi o Banco Mundial, de onde foram extraídos dados referentes às despesas brasileiras e às relações com o comércio exterior. Por último, a Heritage Foundation foi utilizada como fonte dos dados sobre liberdade econômica.

O período analisado foi de 2001 a 2025, conforme a disponibilidade de dados nas bases consultadas.

\section{Procedimento de análise de dados}

A análise dos dados é um processo muito importante ao usar modelos matemáticos, conforme \citeonline{MoniqueGIGO} a qualidade das respostas depende diretamente dos dados usados 
\footnote{O termo coloquial em inglês para essa situação se chama GIGO ou \textit{Garbage In Garbage Out}, que em tradução livre - lixo entra lixo sai.}.
Ou seja, não basta ter fontes confiáveis como o \citem{bcb_dados_abertos} e o \citem{ibge_api}, é necessário um procedimento confiável de ponta a ponta.
Para esse processamento dos dados, foi utilizado a linguagem de programação \textit{Python}
\footnote{Python é amplamente utilizado em computação científica e numérica \citem{python}}
e suas bibliotecas.


O primeiro processo de tratamento foi a conversão dos tipos nativos das APIs para um formato adequado para análise com Python, isso foi feito através da biblioteca Pandas. "Pandas é uma biblioteca de Python de estruturas de dados e ferramentas estatísticas, inicialmente desenvolvida para aplicações de finanças quantitativas." \citem[p. 1, \textit{tradução nossa}]{mckinney2010pandas}.

O segundo passo consistiu no tratamento das observações ausentes e na seleção das variáveis com cobertura suficiente. Na triagem inicial, foram consideradas 26 variáveis; dez foram excluídas por não apresentarem séries completas para o período analisado, restando 16 variáveis para a pesquisa.

Outro procedimento adotado, foi o tratamento e identificação de problemas. A série principal do PIB anual tem a divulgação de forma atrasada. Dessa forma o PIB dos anos de 2024 e 2025 precisaram ser "calculados", na realidade o que foi utilizado foi uma aproximação do PIB anual pelo PIB trimestral e utilizando uma metodologia a do IBGE para a construção do deflator do PIB.

Esse calculo é feito por meio da reconstrução do deflator do PIB, em que pode ser desquita pela expressão \ref{eq:deflator}.

\begin{equation}
	\label{eq:deflator}
	D_t = 100 \prod_{i=1}^{t}
	\left(1+\frac{d_i}{100}\right)
\end{equation}


\(D_t\) é o índice acumulado do deflator do PIB no tempo \(t\);

\(d_i\) é a variação percentual anual do deflator no tempo \(i\);

\(t\) representa o tempo analisado.

Para a remoção da inflação foi utilizada o ano de 2023 como base, assim foi aplicada a expressão \ref{eq:inflacao} na série obtendo um valor de PIB real. O \citeonline{ibge_pib_series} traz a definição de deflator do PIB, porém que se aplica as demais variáveis, em que um deflator é a variação do valor corrente da variável no tempo $(t)$ em relação ao valor da varável do ano $(t)$ a preços do ano anterior, ou seja a variação percentual em relação ao mesmo período do ano anterior.

\begin{equation}
	\label{eq:inflacao}
	PIB_t^{real} =
	\frac{PIB_t^{nominal}}{D_t/100}
\end{equation}

Além do tratamento das variáveis, foram identificadas limitações nas séries. A série populacional apresenta uma quebra em 2022, ano de divulgação dos resultados do Censo Demográfico adiado durante a pandemia, o que levou à revisão das estimativas dos anos anteriores. A série da taxa de desocupação também apresenta uma quebra em 2012, quando a Pesquisa Mensal de Emprego foi substituída pela PNAD Contínua; não há uma série metodologicamente homogênea que cubra todo o período analisado. Essas limitações foram mantidas para avaliar a sensibilidade dos modelos às características dos dados.

Após o tratamento das variáveis, os modelos foram estimados com dados anteriores ao período de avaliação, reservado para os anos de 2023 a 2025. O intervalo de 2002 a 2022 abrange 21 anos-calendário; o número efetivo de observações varia entre as especificações em função das diferenças, defasagens, frequências e disponibilidade das séries. Por exemplo, a amostra do ARIMA em nível contém 21 observações anuais, enquanto a primeira diferença reduz esse número em uma observação; no VAR(1), a defasagem também reduz a amostra efetiva. Nos modelos com validação temporal, os dados anteriores a 2023 foram ainda divididos entre treinamento e validação, conforme descrito nas respectivas seções de resultados. Assim, os períodos e os tamanhos efetivos de amostra são informados para cada aplicação. Como observam \citeonline{santos2022previsao}, o desempenho fora da amostra é central para avaliar a capacidade preditiva dos modelos.

Neste estudo, as variáveis-alvo são o nível do PIB real brasileiro e sua taxa de crescimento, ambos analisados em frequência anual.

O último passo consistiu na avaliação dos modelos segundo quatro critérios: tempo de execução, interpretabilidade qualitativa, raiz do erro quadrático médio (RMSE) e erro absoluto médio (MAE).

O desempenho preditivo foi avaliado pelo \ac{mae}, descrito na equação \ref{eq:MAE}, e pelo \ac{rmse}, descrito na equação \ref{eq:RMSE}.

\begin{equation}
	\label{eq:MAE}
\text{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|
\end{equation}

\begin{equation}
	\label{eq:RMSE}
\text{RMSE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}
\end{equation}


Para \citeonline{kava2022alem}, a interpretabilidade está relacionada à facilidade com que uma pessoa compreende os resultados de um modelo. Neste estudo, essa dimensão foi avaliada qualitativamente, considerando as possibilidades de interpretação econômica de cada modelo.


A dimensão computacional foi representada pelo tempo de execução dos modelos na máquina de teste. Todos os modelos foram executados no mesmo computador, equipado com processador Xeon E5-2680 v4 e 32 GB de RAM, para manter constantes as condições da comparação.

Durante a elaboração deste trabalho, ferramentas de inteligência artificial generativa foram utilizadas como apoio à revisão textual, especificamente para a correção ortográfica e o aprimoramento da coesão e da consistência da escrita. Foram utilizados os modelos GPT-6 Luna (medium) e GPT-6 Astra (high).
